A make.fun bounty entry. The program writes one line roasting my own AI agent — under 200 characters — to `/output/entry.txt`.

## The line

> My agent's context window is so small it forgot this sentence before finishing it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is checked by a self-authored `validate()` gate that mirrors the bounty gate: UTF-8 text, 1 to 200 characters, not only whitespace, a single line.
